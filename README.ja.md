# CoVoyager Travel Chat

[English](README.md) | [日本語](README.ja.md)

地図とチャットが一体になった、ふたり（〜数人）で旅を決めるための旅行プランナーです。国内・海外どちらにも対応します。チャットで相談すると隣の地球儀が候補地へ移動し、ピンを見ながら「ここ混んでるね」「ここはパス」と互いの情報を書き込み、編集できる旅程にまとめます。

## できること

- **チャット × 地図**: AI の提案は地図上の紫のピン（A, B, C…）として表示し、地図はその場所へ移動します。AI が出した場所は OpenStreetMap で位置を照合し、「位置確認済み」か「AI 推定」かを表示します。
- **相談モード**: 「旅程を相談」「行き先探し」（国内外の候補を地球儀に並べる）「現地で再計画」（雨・遅れ・休館などからその日だけの代替案）。
- **旅程の編集**: 日ごとのタブ、ドラッグで並べ替え、開始時刻の固定、滞在時間、休憩、費用、メモ、日の移動、ロック（AI に変更させない）。元に戻す / やり直す（Ctrl+Z）。
- **自動計算**: 徒歩・自転車・車の経路と所要時間（OSRM）。公共交通は概算と明示。22 時超え・時刻に間に合わない予定を警告。
- **ふたりで**: 場所ごとの「行きたい / どちらでも / パス」、場所メモ（混雑・要予約・行かない方がいい…）、行きたい度ボード、各自の条件（徒歩上限・休憩間隔・予算・混雑/暑さ回避など）。必須条件の違反はコードで判定し、AI が勝手に緩めることはありません。
- **公開範囲**: 条件は「ふたりで共有」か「自分だけ」。自分だけの条件は、相手の画面・共有リンク・書き出しに出ません。本人が同意した場合のみ、名前を伏せて AI の提案に反映します。
- **共有**: ライブ共有（招待リンクで 2 台の端末を数秒ごとに同期）、または旅程をそのままリンクで送るスナップショット。JSON の書き出し / 読み込み、端末データの全削除。
- **別行動**: 予定ごとに「行く人」を選ぶと、その区間はひとりずつ並行で時間を計算し、次の全員の予定を「合流」として表示します。
- **旅のしおり**: 旅程・メモ・約束ごとを印刷用ページにまとめ、PDF に保存できます。
- **天気**: 出発 16 日前から現地の予報を表示し、暑い日・雨の日を知らせます。
- **レスポンシブ**: PC は「チャット｜地図｜旅程」の 3 カラム、タブレットは 2 カラム、スマホは上が地図で下がタブ切替（地図の拡大 / 縮小ボタンつき）。

調査の詳細と、地図に Globus ではなく MapLibre を使った理由は [docs/RESEARCH.md](docs/RESEARCH.md) を参照してください（Globus は iOS / Android 向けの SDK で、Web では使えません）。

## はじめかた

Node.js 20.9 以降が必要です。

```sh
git clone https://github.com/moruku36/covoyager-travel-chat.git
cd covoyager-travel-chat
npm install
cp .env.example .env.local   # OPENAI_API_KEY を入れる（空ならデモ応答）
npm run dev                  # http://localhost:3000
```

地図・検索・経路・天気は API キー不要です。`OPENAI_API_KEY` が空の間は、東京・京都・大阪・ソウル・台北・パリ・バンコク・ホノルルの固定データで動くデモ応答になり、課金は発生しません。

### OpenAI API の設定（`.env.local`）

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `OPENAI_API_KEY` | （空） | サーバー側だけで使います。`NEXT_PUBLIC_` を付けないでください |
| `OPENAI_MODEL` | `gpt-5-mini` | Responses API 対応モデル。小さいモデルほど安価です |
| `OPENAI_WEB_SEARCH` | `0` | `1` で OpenAI の web_search ツールを使い、より新しい情報で答えます（1 回あたりの費用が上がります） |
| `OPENAI_MAX_OUTPUT_TOKENS` | `2500` | 1 回の応答の上限 |
| `CHAT_LIMIT_PER_HOUR` / `CHAT_LIMIT_PER_DAY` | `40` / `400` | IP ごと / サーバー全体の AI 呼び出し上限 |
| `APP_ACCESS_CODE` | （空） | 設定すると最初にアクセスコードを入力した人だけが API を使えます。公開デプロイでは必ず設定してください |
| `UPSTASH_REDIS_REST_URL` / `_TOKEN` | （空） | ライブ共有の保存先。空ならサーバーのメモリ（`npm run dev` や単一サーバーの `npm start` では動作。Vercel などのサーバーレスでは Upstash を設定） |

チャットの受け口は `POST /api/chat` です（入力 4,000 文字・旅程 32KB まで、提案は JSON Schema で検証）。仕組みは [docs/DESIGN.md](docs/DESIGN.md) の実装状況を参照してください。

### コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` / `npm start` | 本番ビルド / 起動 |
| `npm run typecheck` | TypeScript の型チェック |
| `npm test` | Vitest（外部 API を呼ばない架空データのテスト） |
| `npm run e2e` | Playwright（ビルド済みアプリをデモモードで操作。`npx playwright install chromium` が必要） |

GitHub Actions が push ごとに型チェック・単体テスト・ビルド・クライアントバンドルへの API 参照混入チェック・PC / スマホ幅の E2E を行います。

## 技術構成

Next.js 16（Pages Router）/ React 19 / TypeScript（strict）/ MapLibre GL JS 6 / zod 4 / dnd-kit / Vitest。地図タイルは OpenFreeMap、地名検索は Photon・Nominatim、経路は FOSSGIS OSRM、天気は Open-Meteo（すべて OpenStreetMap 系またはオープンデータで、帰属表示を画面に出しています）。

## 注意

- 営業時間・料金・混雑は AI の一般知識または利用者のメモであり、リアルタイム情報ではありません。出発前に公式情報を確認してください。
- 予約・決済は扱いません。健康状態の判断や安全の保証もしません。
- 旅程は各端末のブラウザに保存されます。ライブ共有を使うと、共有用の旅程（自分だけの条件は除く）がサーバーに最終更新から 60 日保存されます。
- 公開されるサンプルや fixture はすべて架空です。

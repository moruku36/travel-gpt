# 類似サービス調査と設計判断

調査日: 2026-10-23。各社の公開紹介文・アプリストア説明・比較記事に基づく概要で、実機検証ではありません。

## 類似サービス

| サービス | 特徴（公開情報） | CoVoyager に取り入れた点 / 違い |
| --- | --- | --- |
| Mindtrip | チャット＋地図＋旅程が一画面、予約リンク | チャットと地図の一体化。予約・決済は扱わない |
| Wanderlog | グループでの共同編集、日ごとの地図 | 日ごとの色分けピンと経路、共有リンク |
| Layla | チャット主体、価格・予約重視 | 予約連携はしない。根拠表示と「適用」前の確認を重視 |
| Pathly（AI旅のしおり） | しおりと地図の連動、URL 共有で複数人編集 | URL フラグメントによる招待リンク・スナップショット共有 |
| Funliday | ルート・所要時間の自動計算、AI プランの地図可視化 | 経路と所要時間の自動計算（OSRM）、概算の明示 |
| TripHugger | チャットで相談しながら共同編集 | 発言者付きチャット、メモ・意見の共有 |

比較記事に共通する指摘は「AI の出力は下書きとして検証が必要」。CoVoyager は AI 提案を OpenStreetMap で位置照合し、「位置確認済み / AI 推定 / 手動追加」を常に表示します。

## ふたり旅向けに足したもの（他社に少ない点）

- **行きたい度ボード**: 各自の「行きたい / どちらでも / パス」を集計。未回答は賛成扱いしない。
- **場所メモ**: 「混んでた」「要予約」「行かない方がいい」をピンに付けて共有（地図上に「混」バッジ）。
- **条件の公開範囲**: 条件は「ふたりで共有」か「自分だけ」。自分だけの条件は相手の画面・共有・書き出しに出ず、本人が同意した場合だけ名前を伏せて AI に渡す。
- **決定的チェック**: 徒歩上限・休憩間隔・1日予算・混雑/暑さ回避・パスされた予定を、LLM ではなくコードで判定。
- **現地再計画**: 「雨」「遅れ」「休館」などのワンタップで、その日だけの代替案を提示（ロックした予定は変更しない）。
- **行き先探し**: 行き先未定でも、ふたりの興味から国内外の候補を地球儀に並べる。

## 地図: Globus を採用しなかった理由

[Globus (GLMap)](https://globus.software/) はオフライン地図・検索・経路の SDK ですが、公式 FAQ の対応プラットフォームは iOS / macOS / Android（Flutter・React Native は beta）で、Web ブラウザ向け SDK や公開タイル URL はありません。本アプリは Next.js の Web アプリなので、次の構成にしました。

| 用途 | 採用 | 理由 |
| --- | --- | --- |
| 描画 | MapLibre GL JS v6（globe 投影） | OSS、API キー不要、3D 地球儀 |
| タイル | OpenFreeMap（liberty スタイル） | キー・課金なし、世界対応。SLA はないため本番は自前ホストか契約 provider を検討 |
| 検索・位置照合 | Photon → Nominatim（OSM） | 日本・海外とも対応、ODbL なので帰属表示つきで保存可 |
| 経路 | FOSSGIS OSRM（徒歩/自転車/車） | キー不要。公共交通は時刻表なしの概算と明示 |
| 天気 | Open-Meteo | キー不要、16 日先まで |

旧設計で課題だった Mapbox の「保存許諾」gate（temporary 結果を保存できない）は、OSM データへの切替で解消しています。将来ネイティブアプリを作る場合は、地図部分（`components/MapView.tsx`）を Globus SDK に置き換えられるよう、ピン・経路・フォーカスを props だけで受け渡す構成にしています。

## コストと効率のために削ったもの

- `axios` / `dotenv` / `mapbox-gl` / 旧 `generatePlan.ts` を削除（fetch と Next.js の env 読込で足りる）。
- ストリーミング応答はやめ、Structured Outputs の 1 回呼び出しに統一（提案の検証を一括で行うため）。
- LLM へは直近 10 発言と旅程の要約だけを送り、アシスタント発言は本文のみに圧縮。推論モデルは `reasoning.effort=low`。
- Web 検索ツールは既定で無効（`OPENAI_WEB_SEARCH=1` で有効化）。
- デモ応答は課金対象外としてレート制限から除外。

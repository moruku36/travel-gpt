# Phase 1 固定データモック — レビュー対応と検証

検証日: 2026-10-14。対象: `/mock` の固定データ画面。元実装: Antigravity。レビュー: Claude Code / claude-sonnet-5-5。レビュー後の最小修正: Codex。

国内・海外の架空サンプルを使い、地図プレースホルダー、候補地、チャットの提案、編集可能な旅程を連動する。実 API に接続する本番 MVP の完成を意味しない。

## レビュー指摘と対応

| 指摘 | 対応 |
| --- | --- |
| IME 確定時の Enter 誤送信 | composition/229 を拒否。Shift+Enter は改行 |
| フォーカス不可視 | outline:none を除去し、モック領域に focus-visible を追加 |
| 子ボタン/入力のキーがカードへ伝播 | カード自身を対象とする Enter/Space だけで選択 |
| 重複地点・休憩の時刻と位置 | 重複を拒否。休憩は場所未指定、現行最終 stop 後。挿入位置・時刻・ID・地点を検証し不正案は原子的に拒否 |
| 選択・入力文字ごとに Undo 消費 | 選択を独立 state にし、時刻/滞在は blur/Enter で確定。無変更・不正更新は history/revision 不変 |
| 古いドラフト | 置換/編集/Undo/競合で expired、適用で applied、却下で rejected を記録 |
| ID 衝突 | セッション内単調カウンターを使用。時計固定でも重複しないことを検証 |
| TS/JS の二重ソース | TypeScript を正本にし、既存 TypeScript の限定 loader で同じモジュールをテスト |
| メッセージ状態・適用後の選択 | 通常メッセージを変更せず、更新提案では選択を保持。追加 stop のみ新 ID を選択 |
| 架空根拠の表示 | fixture 作成日時・架空対象日を表示。実在の出典や情報更新時刻として主張しない |

設計・ロードマップ全文を含む最終レビューと追加確認で、固定データモックのコードに阻害する不具合は残っていないとの判定を得た。レビューは読み取りによるコード評価で、試験実行やブラウザ操作とは別の根拠である。

## 完了範囲と残件

固定データ画面モックは今回の対象範囲で完了。状態はブラウザのメモリ内のみで、再読み込み時に初期状態へ戻る。地図の線は架空の描画で、実際の経路ではない。歩行・静かな休息の設定は任意の旅行目安で、最適化や安全保証、健康情報の収集を行わない。

低優先の制限として、架空根拠の表示範囲、手動追加による時刻重複の警告と手動調整、未使用の helper、ページ全体の E2E 未実施が残る。操作確認では国内/海外切替、候補・ピン選択、時刻/滞在、休憩、上下順序、ドラフト/適用/却下/競合、Undo、IME、フォーカス、狭い画面を確認する。

全体設計上 Phase 1 に含まれる保存/export/import、server LLM/schema/API、Mapbox と保存許諾付き情報源、費用/回数制御、DST/複数日/通貨計算は未実装。Phase 2 の同行者合意、Phase 3 の任意の機微情報処理も未実装。このモックの完了を、それらの完了や本番運用可能性とは解釈しない。

実行方法と機能対応は[実装報告](MOCK_IMPLEMENTATION_REPORT.md)、全体の要件は[設計](DESIGN.md)と[ロードマップ](ROADMAP.md)を参照。
